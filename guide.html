Installation

1

Install OpenClaw

Open PowerShell as Administrator and run:

PowerShell (Admin)
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
PowerShell
npm install -g openclaw@latest

Requires Node.js 22+. Install Node first if needed: winget install OpenJS.NodeJS.LTS

2

Run Onboarding

This wizard sets up everything — API key, gateway, and agent config:

PowerShell
openclaw onboard --install-daemon

When it asks for a provider, pick one:

Recommended — Free Tier

Google Gemini

Get your key at aistudio.google.com → Get API Key

Alternative — Paid

Anthropic (Claude)

Get your key at console.anthropic.com → API Keys. Requires credit balance.

Alternative — Paid

OpenAI (GPT)

Get your key at platform.openai.com → API Keys

3

Verify It Works

Check the gateway is running and open the dashboard:

PowerShell
openclaw gateway status
PowerShell
openclaw dashboard

The dashboard opens in your browser. Type a test message. If the AI replies, you're set.

Checkpoint: If you got a reply in the dashboard, your AI is working. Everything below connects it to Telegram and X.

Connect Telegram

4

Create a Telegram Bot

Open Telegram, message @BotFather, and send:

Telegram → @BotFather
/newbot

Follow the prompts. BotFather gives you a bot token like 7123456789:AAH.... Copy it.

5

Connect Telegram to OpenClaw

PowerShell
openclaw channels login telegram

Paste your bot token when prompted. Then restart the gateway:

PowerShell
openclaw gateway restart

Now message your bot on Telegram. The AI should reply. You can ask it to generate tweets, posts, or anything.

Connect X (Twitter) via Browser

6

Log into X in OpenClaw's Browser

OpenClaw has a built-in browser it can control. Log into X.com:

PowerShell
openclaw browser login

A browser window opens. Navigate to x.com and log in with your X account. Once logged in, close the browser. OpenClaw remembers the session.

Important: Leave the browser session active. Don't log out of X. OpenClaw uses this session to post tweets.

Set Up the Daily Routine

7

Create Your Brand Memory

Tell OpenClaw who you are so all content matches your voice:

PowerShell
notepad C:\Users\HP\.openclaw\workspace\MEMORY.md

Paste and customize:

MEMORY.md Template
# My Brand ## Who I Am Name: [Your Name] Niche: [e.g., AI tools, productivity, tech] Tone: Casual, confident, helpful ## Target Audience Young professionals who want to use AI to work smarter ## Content Pillars 1. AI tools and how to use them 2. Productivity tips 3. Making money with tech 4. My personal journey ## Rules - Tweets: under 270 characters, punchy, hook first - LinkedIn: professional but not stiff, 150-250 words - Facebook: conversational, end with a question

Save and close. OpenClaw indexes this automatically.

8

Schedule Daily Tweet Generation

Set up a daily cron job that generates and delivers tweets to Telegram:

PowerShell
openclaw cron --help

Or message your Telegram bot daily with prompts like:

Message to Your Telegram Bot
Generate my 3 tweets for today. 1 value tweet teaching something about AI 1 engagement tweet asking a question 1 personal observation Under 270 characters each. Hook in the first line. Match my brand voice.

The AI generates the tweets and sends them back to you on Telegram.

9

Post to X via Browser

After getting your tweets on Telegram, tell the AI to post them:

Message to Your Telegram Bot
Post this to X right now using the browser: [paste your tweet here]

Or schedule it for the right time:

Message to Your Telegram Bot
Post these 3 tweets to X today using the browser. Post the first at 9 AM, second at 12 PM, third at 5 PM. 1. [first tweet] 2. [second tweet] 3. [third tweet]
How it works: OpenClaw opens its built-in browser, navigates to X.com (where you're already logged in), types the tweet, and hits post. It controls the browser like a real person would.
